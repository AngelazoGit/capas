// pipeline

A file is layers. It reads all of them.

Each block runs the same four steps; children run the moment they appear, in parallel, deduplicated by SHA-256.

01 — IDENTIFY

By content

Reads the format from the magic bytes, never from the file name.

02 — ANALYZE

Pull it apart

Headers, symbols, disassembly, bytecode, strings and entropy.

03 — EXTRACT

Next layer

Decompress, open the container, carve embedded files by signature.

04 — REPEAT

Until it stops

Every child goes back to step one until no layers remain.

No. CAPAS reads and extracts to inspect; it never executes what you give it, and external tools run with a timeout. Everything stays on your machine.

A single portable Windows .exe, no install. It also builds on Linux and macOS. English and Spanish, four themes, GUI and console.
