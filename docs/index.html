// capabilities

What it does on every block.

01Extraction
Recursive layers

zip, 7z, RAR, CAB, MSI, ISO, CHD, gzip, xz, zstd, lz4, tar, .deb, PDF streams — all built in, nothing to install, in parallel across every core.

02Detection
By content

Hundreds of formats read from their bytes — Windows, macOS, Linux, Android/iOS, consoles — not guessed from the extension.

03Decompile
Binaries & bytecode

Its own decompilers: Java and Python (.pyc 3.6–3.14) to readable source; DEX, WASM; x86/x64, ARM64, ARM and MIPS disassembly. No JDK or Python needed.

04Confidence
With evidence

Every file is marked confirmed, compatible, probable or unknown — with the reason: a signature, a manifest reference, or nothing.

05Index
Relations & SQLite

Links files that belong together and writes a queryable index keyed by SHA-256, so versions diff cleanly and duplicates count once.

06Audit
Packs & mods

Asset packs and mods get an APPROVED / QUARANTINE / REJECTED verdict from escape paths, manifest validity and native code.

07Unpack
Engine bundles Pro

Opens Unity (UnityFS, LZ4/LZ4HC) and Godot (.pck) bundles and sends their inner files back through the pipeline.

08Keys
Protected ZIPs

Opens ZipCrypto and AES archives you're entitled to open, with an attempt cap, so it keeps peeling. It does not break strong crypto.

// pipeline

A file is layers. It reads all of them.

Each block runs the same four steps; children run the moment they appear, in parallel, deduplicated by SHA-256.

01 — IDENTIFY

By content

Reads the format from the magic bytes, never from the file name.

02 — ANALYZE

Pull it apart

Headers, symbols, disassembly, bytecode, strings and entropy.

03 — EXTRACT

Next layer

Decompress, open the container, carve embedded files by signature.

04 — REPEAT

Until it stops

Every child goes back to step one until no layers remain.

// faq

Straight answers.

Does it run the files?
No. CAPAS reads and extracts to inspect; it never executes what you give it, and external tools run with a timeout. Everything stays on your machine.
What does it run on?
A single portable Windows .exe, no install. It also builds on Linux and macOS. English, Spanish, Chinese, Russian and Portuguese, five masks, GUI and console.
Does it open password-protected ZIPs?
Yes, the ones you're entitled to open. It tries the passwords you give it, a common-password list and your dictionary. It also tells the encryption apart: legacy ZIPs (ZipCrypto) can be recovered WITHOUT the password if you provide an unencrypted copy of one of their files (built-in known-plaintext attack); modern AES encryption cannot be broken, only opened with the password.
Do I need to install anything else?
No. Unpacking (7z, RAR, CAB, MSI, ISO, CHD), decompiling Java and Python, reading DEX and WebAssembly and disassembling x86/ARM/MIPS are all inside the .exe. Only Ghidra, RetDec or radare2 are optional extras for deep reverse engineering.
What's free?
The whole analysis engine: extraction, detection, classification, confidence, relations, the SQLite index, package audit, the password module and every report.
How does a license work?
A signed file you drop next to the binary, verified offline with Ed25519 — no account, no server. The edition you bought keeps working; updates are included for a year.
Can I use it on a game server?
Yes. Studio is licensed for server use and several machines, with CI exit codes and a local API to gate uploads before they load.
